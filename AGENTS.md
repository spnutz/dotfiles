# Agent instructions

## Attribution

For commits containing work generated or modified by Codex, append exactly once after a blank line:

```text
Co-authored-by: Codex <noreply@openai.com>
```

Apply this to Git commits and GitHub API/plugin commit message arguments. Preserve existing authors and co-authors. Do not attribute unrelated work to Codex. Add `Generated with [Codex](https://openai.com/codex/).` exactly once to pull request descriptions for Codex-assisted changes. Attribution does not change the PR creator or guarantee a linked GitHub avatar. Do not rewrite published history solely for attribution without explicit user authorization.
